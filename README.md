# 💫 About Me:
🚀 I’m a **Cloud Engineer** focused on designing, automating, and optimizing secure AWS cloud infrastructure for production environments.

☁️ I specialize in building **scalable, resilient, and cost-optimized architectures** using Terraform, CloudFormation, and cloud-native AWS services.

⚙️ Currently working on:

- Infrastructure as Code (Terraform modules & reusable architectures)
- CI/CD automation with GitHub Actions & AWS CodePipeline
- Containerized deployments using Docker, ECS & Fargate
- Secure multi-AZ & multi-region cloud architectures
- GenAI integrations using AWS Bedrock

🤝 I’m looking to collaborate on:

- DevOps automation platforms
- Infrastructure standardization
- AI-powered cloud applications

🛠️ I have strong hands-on experience with:

- AWS (EC2, S3, RDS, Lambda, VPC, IAM, Route 53, CloudWatch, ECS, EKS)
- Infrastructure as Code (Terraform & CloudFormation)
- Monitoring & Observability (CloudWatch, Prometheus, Grafana)
- Networking & Security (VPC design, IAM policies, WAF, Shield, Secrets Manager)
- Cost Optimization

🌱 Currently learning:

- Advanced Kubernetes (EKS)
- Distributed system design patterns
- High-scale architecture optimization

🎤 I’ve represented my organization at major industry events including tech summits, where I demonstrated live Generative AI applications and explained complex cloud architectures to both technical and non-technical audiences.

💬 Ask me about:

AWS Architecture | DevOps Pipelines | Terraform Best Practices | Cloud Security | Cost Optimization | Production Debugging | Generative AI on AWS

⚡ Fun fact:

I enjoy designing architecture diagrams as much as writing infrastructure code — and I love simplifying complex systems for others.
